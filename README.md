# DEEPER

A browser puzzle game with 100 levels of rising difficulty.

Inspired by The Impossible Quiz (inversion, memory across levels, wordplay, observation) and Notpron (progressive challenge).

- No login
- One fair hint per level
- Resume codes
- Mobile sensors in later levels
- Visual depth progression (warm paper → cooler/darker)

The further you go, the more there is to find.

Play locally by opening index.html, or deploy the repo to Vercel.
